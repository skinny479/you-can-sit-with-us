# You Can Sit With Us Foundation website

Static site (HTML/CSS/JS, no build step) for the You Can Sit With Us Foundation, a 501(c)(3) in Springdale, Arkansas. Hosted on GitHub Pages.

## Pages
Home, About, Programs, Get Involved, Donate, Contact, 404.

## Publish
Settings > Pages > Source: Deploy from a branch > `main` / root.

## Editing
Pages are generated by `tools/build.py` (shared header, footer, and page content in one place).
Edit content there, then run `python3 tools/build.py .` from the repo root and commit the regenerated HTML.
